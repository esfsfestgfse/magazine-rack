# Magazine Rack live audit — 2026-09-25

## Scope

This audit covered the deployed root page, the live shelf loading path, source-health labels, reader startup, and the production shelf catalog. It also checked the release gates after the repair pass.

## Verified working

- The deployed root renders 52 shelves and lower shelves complete loading instead of remaining on `Waiting…`.
- Generated title covers appear when a provider has no usable cover URL.
- Comic Book Plus opens an actual in-app sequential reader; the smoke item exposed 67 pages with previous/next controls and a page slider.
- Cached or fallback content remains visible when a provider is unavailable.
- Adult shelves remain at the bottom of the rack.
- `pnpm run check` passes the required-file, shelf-parity, release-gate, API, CORS, and rate-limit checks.

## Regressions found and repaired

### Character shelves

Internet Archive's broad text index was admitting names, essays, catalogs, games, toys, and historical references. This was visible on Batman, Spider-Man, Superman, and Archie. The production page now applies shelf-specific relevance gates after normalization, and the mirrored catalog queries carry matching exclusions.

### Manga classification

The Manga query could admit cookbooks, Bibles, textbooks, tutorials, figurines, coloring books, and art/design manuals because they contained the word `manga`. Those classes are now excluded at both query and client-filter levels.

### Source health semantics

A failed refresh could label a shelf with retained cards as `offline`, which made usable stale data look broken. Retained content now displays as `fallback`/degraded while an empty provider failure can still display as offline.

## Remaining risks

- The production page is still a large inline module. `apps/web/src/` contains a parallel catalog contract, so future edits can drift unless the build is consolidated.
- Europeana remains image-only by design and should stay visibly secondary.
- Open Library can return borrow/preview records that require the user's official Open Library flow; the Worker must not store credentials.
- Internet Archive availability varies by item. A successful reader shell does not guarantee that every borrow-restricted scan can be embedded.

## Next regression gates

1. Add fixture-based tests for the character and Manga relevance filters.
2. Add a live audit artifact containing per-shelf population, readable rate, cover rate, duplicates, and provider status.
3. Consolidate the inline production catalog into the canonical module without changing the public shelf contract.
4. Run narrow-screen reader tests after the next deployment.
